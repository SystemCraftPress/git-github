# Git & GitHub Companion Guide

_Practical Developer Reference_

From First Commit to Confident Collaboration

A concise, practical guide for developers. Part of the SystemCraft™ Companion Guide Series.

## About this Repository

This repository is the companion to the **Git & GitHub Companion Guide** — a practical, no-fluff reference for developers who want to understand what Git is actually doing, not just memorize commands.

It's free and open: a cheat sheet, quick-reference tables, worked examples, hands-on exercises, and diagrams covering the Git and GitHub workflow most developers use every day — branching, commits, Pull Requests, and merge conflicts.

## Topics Covered

- Core daily Git workflow (pull → branch → commit → push → PR → merge)
- Branching strategy and naming conventions
- Writing commits that don't suck
- Pull Requests — opening, reviewing, and merging
- Merge conflicts — reading them and resolving them calmly
- Team workflow rules that keep repositories stable
- Quick-reference command tables
- Scenario-based troubleshooting
- Full Git & GitHub glossary

## What Is In This Repo

- **`cheatsheet/`** — a free one-page Git cheat sheet: the daily workflow loop, essential commands, and golden rules
- **`reference/`** — quick-reference command tables: resets and undos, status codes, branch naming, commit types
- **`examples/`** — worked examples: the daily workflow end-to-end, commit message patterns, branch naming, and a full merge-conflict walkthrough
- **`exercises/`** — hands-on practice: your first branch and commit, simulating and resolving a real conflict, writing an actual Pull Request
- **`diagrams/`** — visual diagrams of the workflow loop, the branch lifecycle, and the conflict-resolution decision flow
- **`preview/`** — a look at the full Companion Guide's cover and interior layout
